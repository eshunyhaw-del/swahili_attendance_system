S SWASA Design System

University Attendance System

Design language & components

The shared visual system for the student, teaching assistant and lecturer experiences. Flat neutral surfaces, subtle shadows, restrained radii, and a fixed, accessible vocabulary for attendance status. Every screen is built from these components so the system reads as one coherent institutional product.
