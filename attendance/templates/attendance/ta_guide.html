TA Quick Guide

Everything you need to know to run your sessions
1
Using Your Dashboard
Your dashboard shows allsessions grouped by course. Each course card lists every week as a tab at the top.
Click aWeek tab to open that session. You'll see the date, time, topic, and the list of enrolled students below.
Thestudent count chip next to the session date shows how many students are registered for that course.
2
Generating Attendance Codes
Generate All — click the green button at the top of a session to generate codes for every student at once. You'll be asked to confirm before it runs.
Generate one — find the student in the table and click the greenGenerate button in their row. The code appears instantly without reloading the page.
Once a code is generated, clickMark Given after you hand it to the student. This changes the status fromPending toGiven.
Codes remain on the current week tab after generation — the page does not reload or switch tabs.
3
Understanding Code Statuses
Not generated — no code has been created for this student yet for this session.
Pending — a code was generated but has not been given to the student or used yet.
Given — you marked the code as distributed. The student has the code but hasn't submitted attendance yet.
Used — the student submitted their attendance using this code. No further action needed.
4
Managing Your Courses
Go toManage Courses in the sidebar to see all available levels. Your currently assigned ones are shown in green.
Check any level you want to add. New levels will appear on your dashboard after saving.
Uncheck a green level to remove it. ClickSave Changes to confirm. The level will no longer appear on your dashboard.
5
Sending Announcements
ClickAnnouncements in the sidebar. Write a subject and your message, then choose which levels to target — or leave all unchecked to send to every student in your levels.
Students receive the announcement as an email. The subject line will be prefixed with[SWASA] so it is easy to identify.
All past announcements are listed below the compose form, showing how many students received each one.
Only students registered in active-semester courses for your assigned levels will receive the email.
6
Viewing Your History
ClickMy History in the sidebar for a full record of every session — codes generated, given out, used, and the overall usage rate per week.
Theusage rate bar for each session shows what percentage of generated codes were actually used to submit attendance.
