TA quick guide

Everything you need to run your sessions.

1Using your home screen{% icon "chevron-down" 20 "chev" %}
{% icon "house" 18 %}
Home shows your totals, then each course. For every course the current week opens by itself: today's session, or the next one if there is none today.
{% icon "calendar-days" 18 %}
You see the week before and after it. Tap Show all sessions under a course to list every week.
{% icon "users" 18 %}
Tap any week to open it. You get the date, time and venue, then a card for every enrolled student.
2Generating attendance codes{% icon "chevron-down" 20 "chev" %}
{% icon "zap" 18 %}
Generate all codes: the blue button at the top of an open week. It creates a code for every student at once and asks you to confirm first.
{% icon "key-round" 18 %}
Generate one: find the student's card and tap Generate code. The code appears on the card straight away.
{% icon "send" 18 %}
After you hand a code to a student, tap Mark given. The badge changes from Pending to Given.
{% icon "info" 18 %}Use the search box and the All, Pending, Given and Used filters to find a student quickly.
3Understanding code statuses{% icon "chevron-down" 20 "chev" %}
{% icon "minus" 18 %}
No code: nothing has been generated for this student in this session yet.
{% icon "clock" 18 %}
Pending: a code exists but you have not marked it as given and the student has not used it.
{% icon "send" 18 %}
Given: you marked the code as handed over. The student has not submitted attendance yet.
{% icon "check" 18 %}
Used: the student submitted attendance with this code. Nothing more to do.
4Managing your courses{% icon "chevron-down" 20 "chev" %}
{% icon "ellipsis" 18 %}
Tap More, then Manage courses. Levels you teach are listed first and already ticked.
{% icon "plus" 18 %}
Tick a level to add it. New levels appear on Home after you save.
{% icon "x" 18 %}
Untick a level to remove it, then tap Save changes.
5Sending announcements{% icon "chevron-down" 20 "chev" %}
{% icon "megaphone" 18 %}
Tap More, then Announcements. Pick the course, write a subject and your message, and send.
{% icon "bell" 18 %}
Students registered for that course see it in their notification bell and on their Notifications page.
{% icon "history" 18 %}
Earlier announcements are listed below the form with the number of recipients. You can edit or delete them there.
6Viewing your history{% icon "chevron-down" 20 "chev" %}
{% icon "history" 18 %}
Tap History in the bottom bar for a record of every week you generated codes for: enrolled, generated, given out and used.
{% icon "check" 18 %}
The usage bar shows what share of the generated codes students actually used.
{% icon "calendar-days" 18 %}
Weeks where you have not generated anything yet sit under Sessions without codes.
